Comparing Regularised Learning Methods Across Two Datasets

A rigorous, cross-validated comparison of six model families — from linear regression to neural networks — answering a practical question: which method is right, and when? The results reveal when regularisation actually helps, and how a single metric can hide a broken model.

Headline findings

Three results a hiring team can read in thirty seconds — each backed by the interactive evidence below.

◱

Regularisation is conditional

It gave no measurable gain on the low-dimensional dataset (13 predictors) but consistently improved accuracy on the high-dimensional one (39 predictors) — its value scales with the predictor-to-data ratio.

◎

Accuracy vs interpretability

The neural network won on raw accuracy but explained nothing. Lasso predicted almost as well and revealed which factors drove each outcome — often the more useful model.

⚠

A metric can hide a broken model

On imbalanced data, two models hit ~85% accuracy by labelling everyone a pass — catching 0% of at-risk students. Only balanced accuracy and recall exposed it.

Approach

The same toolkit was applied to both problems on one shared 10-fold split, so every difference reflects the method — not luck in the data split.

Regression problems were also cast as classification to test kernel and penalised classifiers.

Why it matters

Model selection is contextual. There is no universally best method — the right choice depends on dimensionality, class balance, and whether you need prediction or explanation.

Metrics can mislead. Reporting balanced accuracy and recall alongside accuracy prevented a confidently wrong conclusion on imbalanced data.

Rigour by design. A shared fold split, fixed seeds, and leakage prevention make every comparison fair and reproducible.

Communicated for decisions. Findings were framed for a non-technical reader — the difference between an analysis and an insight.
